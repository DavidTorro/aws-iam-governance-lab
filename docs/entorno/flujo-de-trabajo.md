# Flujo de trabajo

La práctica se realizará en Floci con AWS CLI. El enunciado original está en `enunciados/` y no se publicará.

1. Comprobar las herramientas y arrancar el entorno local.
2. Crear grupos, usuarios y pertenencias.
3. Asociar a cada grupo su política JSON.
4. Consultar el simulador IAM y guardar las capturas.
5. Parar y reiniciar Floci para comprobar el carácter efímero del entorno.
